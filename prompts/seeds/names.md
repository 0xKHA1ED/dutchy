# Names

Character names come from here, never from the model's own choice, because models reuse the same handful of names across every story. The runner picks the region from the rolled place (or from a character's background if the forge sets one), then draws given names and family names from that region's lines. Places tagged `[anywhere]` draw from a random region.

Format for the dice: each line starting with `- ` is one region. `given:` and `family:` are comma-separated lists. Names mix generations on purpose; the forge should keep a name that fits the character's age and swap it for another from the same line if it doesn't, saying why. Names on the banned list in `_shared/banned-defaults.md` are deliberately absent.
